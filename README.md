# Melo WG

Клиент WireGuard для Windows 10/11 с раздельным туннелированием по приложениям.

- **Весь трафик** — всё идёт через туннель.
- **Только выбранные** — через туннель идут только программы из списка, остальное напрямую.
- **Кроме выбранных** — через туннель идёт всё, кроме программ из списка.
- **Локальная сеть напрямую** — роутер, принтеры, NAS и прочие устройства домашней сети (10.x, 172.16–31.x, 192.168.x, link-local, мультикаст) не заходят в туннель.

## Установка

1. Установите [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0), если его ещё нет.
2. Скачайте `MeloWG-<версия>-win-x64.zip` со страницы [Releases](../../releases) и распакуйте в любую папку.
3. Запустите `MeloWG.exe` (папка `core` должна лежать рядом). Программа запрашивает права администратора: без них Windows не даст создать сетевой адаптер.

## Использование

1. Нажмите на карточку «Туннель» → «Импорт из файла…» (или перетащите `.conf` в окно).
2. Выберите режим и добавьте программы: «Запущенные», «Обзор…» или перетаскиванием `.exe` / ярлыка.
3. Нажмите большую кнопку.

Изменения режима, списка и LAN во время подключения применяются кнопкой «Применить» (быстрое переподключение). Крестик сворачивает окно в трей; выход — через меню значка в трее.

Журнал (значок часов в заголовке) показывает события клиента, предупреждения и ошибки ядра. Переключатель «Подробно» добавляет строку на каждое соединение и DNS-запрос — по ним видно, какая программа и по какому правилу пошла в туннель или мимо него. Режим сбрасывается при перезапуске: строк сотни в секунду, и вместе они составляют историю посещённых сайтов.

## Как это устроено

Обычный WireGuard для Windows маршрутизирует только по IP-адресам, а выбор по программам требует драйвера. Поэтому ядром служит [sing-box](https://github.com/SagerNet/sing-box) 1.14.4 (`core\sing-box.exe`, GPLv3):

- TUN-адаптер `MeloWG` (драйвер wintun, подписан WireGuard LLC) забирает трафик;
- правила по имени `.exe` (без учёта регистра) решают: в WireGuard-туннель или напрямую;
- WireGuard работает внутри ядра (userspace), прямые соединения привязаны к физическому адаптеру;
- `strict_route` (WFP) блокирует DNS-запросы мимо TUN, они перехватываются ядром.

DNS: в режимах «Весь трафик» и «Кроме выбранных» — DNS из конфига через туннель (без конфига — 1.1.1.1 через туннель). В режиме «Только выбранные» — системный DNS: DNS-запрос в Windows делает служба DNS-клиента, привязать его к программе нельзя.

Если у туннеля нет IPv6, IPv6-трафик туннелируемых программ отклоняется (программы переходят на IPv4), а не утекает мимо VPN. Адреса вне `AllowedIPs` идут напрямую, как в обычном WireGuard.

Конфиги хранятся в `%APPDATA%\MeloWG\tunnels`, зашифрованные DPAPI (ключ вашей учётной записи Windows). Ядро получает конфиг через stdin — приватный ключ не пишется на диск открытым текстом. Если клиент аварийно завершится, ядро завершится вместе с ним (Job Object), правила WFP и адаптер удалятся системой.

## Ограничения

- Программы сопоставляются по имени файла: добавляйте exe самой игры/программы, а не лаунчера. Приложения на WebView2 работают через `msedgewebview2.exe`.
- В режимах «Только выбранные» и «Кроме выбранных» через ядро проходит весь трафик (так ядро узнаёт, какой программе он принадлежит), поэтому скорость ограничена userspace-реализацией — обычно сотни Мбит/с.
- Нет kill switch: если ядро упадёт, трафик пойдёт напрямую (клиент покажет уведомление).
- AmneziaWG-конфиги (параметры `Jc`, `H1`…) не поддерживаются.
- Не включайте одновременно туннель в официальном WireGuard — маршруты будут конфликтовать.

## Сборка

Нужен .NET 10 SDK (`winget install Microsoft.DotNet.SDK.10`).

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1 -Zip
```

Скрипт при необходимости скачивает ядро (`tools\get-core.ps1`: официальный релиз sing-box с проверкой SHA256 — сам бинарник в git не хранится), прогоняет самопроверку (`tests\MeloWG.SelfTest`: разбор `.conf`, подсети, генерация конфигов во всех режимах с проверкой `sing-box check`, запуск/остановка ядра) и публикует `dist\MeloWG` (с `-Zip` — ещё и архив для релиза).

Отладка интерфейса без прав администратора: `dotnet build src\MeloWG -p:MeloNoElevate=true`, превью окон в PNG — `MeloWG.exe --render-preview <папка>` (Debug).
